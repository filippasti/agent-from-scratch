# Agent from Scratch

Ein KI-Agent mit Tool-Calling, bewusst ohne Framework gebaut.
Ziel ist zu verstehen, was unter der Haube passiert: Werkzeuge
beschreiben, Aufrufe erkennen, ausführen, Ergebnis zurückgeben –
in einer Schleife, bis eine endgültige Antwort kommt.

**Status:** In Arbeit.

## Technik

- Python
- Anthropic API (direkt, ohne LangChain)

## Geplant

- Mehrere Werkzeuge mit Parametern
- Eigener MCP-Server
